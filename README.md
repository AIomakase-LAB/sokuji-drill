# 即時判断ドリル

救急活動の「数秒でとっさに判断する力」を鍛える訓練アプリ(PWA)。
指令内容から引き継ぎまでの9場面を、制限時間つきで答えていく。GitHub Pages で配信し、データは管理者の Google スプレッドシートに保存する。
構成は筋トレメニュー(`kintore-menu`)と同じ。

> 訓練用です。実際の活動は所属のMCプロトコールに従ってください。
> 実在の傷病者の個人情報(氏名・住所・電話番号・生年月日など)は入力しないでください。

## 機能
- **ドリル**: 9場面(場面数・場面名は症例ごとに変更可)、制限時間 5/10/15/20秒、選択式(毎回シャッフル)/声出し(模範解答→自己評価)、ランダム出題、難易度・カテゴリの絞り込み、**弱点場面だけ**の出題
- **記録**: 1回の訓練を場面ごとの正誤・所要時間つきで保存。履歴、カレンダー、連続日数、今週の回数、自己ベスト、直近の推移、18週の訓練日、場面別・カテゴリ別の弱点、目標(週◯回・平均◯秒以内)、CSV/JSON書き出し
- **症例をみんなで作る**: スマホで入力しやすい作成画面、下書き → レビュー待ち → 承認済み(承認者だけが公開)、差し戻しコメント、複製して派生症例、JSON取込/書出(プロトタイプの形式もそのまま取り込める)、見直しの目安(根拠なし・正解だけ長い等)、個人情報らしき記述の警告
- **オフライン**: 圏外でも訓練・記録でき、つながったときに自動送信。ホーム画面に追加して使える
- **端末の引き継ぎ**: 設定の「引き継ぎコード」を新しい端末に貼ると、履歴ごと移せる
- **デモ**: 接続せずに、この端末の中だけで全機能を試せる
- 同梱のサンプル3症例(プロトタイプから移行。MCプロトコールとの照合は未実施)

## 構成
- 画面: このリポジトリ(静的ファイルのみ、ビルド不要)
  - `logic.js` 採点・検証・集計(画面に依存しない。テストあり)
  - `core.js` 状態・通信・送信キュー / `drill.js` ドリル / `views.js` 履歴・分析・症例・設定 / `main.js` 起動
  - `samples.js` サンプル3症例 / `sw.js` オフライン用 / `version.js` 版番号
- データ API: `AIomakase-LAB/gas-projects` の `projects/sokuji-drill`(Google Apps Script)

## 使い始めるまで
1. API を用意する(`gas-projects` の `projects/sokuji-drill/README.md` の「初回セットアップ」)
2. このリポジトリの Settings → Pages で、`main` ブランチの `/(root)` を公開する
3. 公開された URL をスマホで開き、「設定」シート B2 の**接続コード**とニックネームを入れて接続する
4. 承認する人は、設定タブで「設定」シート B3 の**承認者の合言葉**を入力する
5. iPhone は Safari の共有 →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」

## 更新するとき
画面のファイルを変えたら、`sw.js` の `CACHE` と `version.js` の版番号を上げる(端末のキャッシュが入れ替わる)。

## テスト
```bash
node --test test/logic.test.js                                   # 採点・検証・集計
GAS_DIR=../gas-projects/projects/sokuji-drill node test/e2e.js    # ブラウザでの通し確認(Playwright)
```
`e2e.js` は、画面と、Apps Script の `code.js` をメモリ上で動かすモック API をローカルで起動し、スマホ画面サイズで操作を確認する。
作成者 → 承認者 → 隊員の流れ、オフラインからの再送、引き継ぎコードなどを確認する。

手元で触るだけなら次で起動できる(本物のスプレッドシートには書かない)。
```bash
GAS_DIR=../gas-projects/projects/sokuji-drill node dev/server.js 8080
```
